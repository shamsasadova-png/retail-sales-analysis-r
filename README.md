# Retail Sales Analysis (R)

Exploratory data analysis of retail sales data using R, examining 
revenue by category, region, and monthly trends.

## Dataset
Superstore Sales Dataset (retail sales data, 2015–2019) — sourced 
from Kaggle.

## Key Findings
- Technology generated the highest total sales, followed by 
  Furniture and Office Supplies
- The West region had the highest sales, while South had the lowest
- Monthly sales show a clear upward trend from 2015 to 2018
